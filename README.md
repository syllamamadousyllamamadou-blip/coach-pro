# COACH PRO — Application Web Coach Sportif Privé

Application professionnelle conçue pour les coachs sportifs privés :
- Tableau de bord complet et gestion des athlètes / clients
- Bilan métabolique et corporel automatisé (IMC, Métabolisme de base, Taux de masse grasse, Poids idéal)
- Questionnaires d'évaluation 21 facteurs & suivi morphologique
- Gestion des forfaits, abonnements & tarification en FCFA
- Édition et impression thermique directe (Reçus Bilan, Forfait & Programme)
- Calculateur Flash et outils d'ajustement en temps réel
- Sauvegarde et persistance locale des données

## Technologies
- HTML5 / Vanilla CSS / JavaScript ES Modules
- Tailwind CSS
- Déploiement Vercel
